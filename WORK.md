# WORK

Goal: an own Kenshi multiplayer (own server + client mod) that works better than AnarchyKenshi and is fully under the user's control, without depending on another mod (RE_Kenshi); everything is extracted from the client DLLs first (the original server is not available).

- Route: own server and own client mod, AnarchyKenshi only a reference; plan in `docs/plan-first-playable.md`. M0 done. M0b done (own Ogre-plugin loader, own address table for 1.0.65 and 1.0.68, early DXGI fix, no KenshiLib; user runs with and without RE_Kenshi passed, probe answered on 1.0.68). M1 done (own pose read and logged; user's run passed, `docs/client.md` "Own pose (M1)"). M2 done (own protocol `docs/protocol-ours.md`, relay server `kp-server`, test bot `kp-bot`, tests pass; `net/`). M3 built (core DLL `KenshiPureCore.dll` + network thread, `docs/client.md` "Networking and the core DLL (M3)"; `kp-core-test` passes incl. a 60 s stall). M3 done (user's run: bot's circle in KenshiPure.log, user's walk in the server log, save load kept the connection; in-game tests start with `start-test-server.cmd`). M4 done (a borrowed NPC follows the bot with the walk order and its own AI on; `docs/client.md` "Stand-in body (M4)"). In-game tests run unattended: `scripts/run-game-test.ps1` (Kenshi windowed on the second monitor, save loaded by the plugin, killed without saving; `-Cfg`, `-Steps` save/load, `-BotSeconds`, `-BotRestart`, `-SaveCopy`). M5 done (own body per remote player, drive `auto`, save guard; `docs/client.md` "Remote bodies (M5)"). Next: M6 (two real players).
